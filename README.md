# Книга заклинаний — D&D 5e (2014) + Laserllama

Сайт для сравнения официальных заклинаний D&D 5e (редакция 2014, 14 книг, 525 заклинаний) с хоумбрю Laserllama
(«Compendium of Spells» v.0.5, 122 заклинания, из них 77 — альтернативные версии официальных). Весь сайт закрыт паролем.

## Как устроено

- Интерфейс: Preact + TypeScript + Vite (`src/`), хостинг — GitHub Pages, деплой через GitHub Actions
  (`.github/workflows/pages.yml`) при каждом push в `main`.
- Данные публикуются только в зашифрованном виде: `src/data/spells.bin` (AES-256-GCM, ключ из пароля через
  PBKDF2-SHA256, 600 000 итераций). Браузер расшифровывает файл после ввода пароля и запоминает ключ, повторно
  пароль не спрашивается. Исходные тексты официальных книг в репозиторий не попадают (см. `.gitignore`).
- Источники: английский текст и параметры официальных заклинаний — 5etools; русский текст — ttg.club;
  Laserllama — извлечено из PDF (`scripts/extract_laserllama.py` → `data/laserllama/spells.en.json`);
  русский перевод Laserllama и Linked Glyphs — `data/translations/out/` (неофициальный).
- `scripts/build-data.mjs` собирает всё в `data/build/spells.json` и проверяет, что текст не потерялся.
- Классы в фильтре разделены: официальные классы D&D используют официальные списки заклинаний, классы Laserllama —
  списки из его документов классов (`data/laserllama/class-lists/*.json`; туда входят и официальные заклинания).
  Для класса Laserllama без такого документа используются строки «Classes» из компендиума.
  Добавить документ класса:
  `python -P -E scripts/extract_class_spell_list.py "<PDF>" Bard "Laserllama: Alternate Bard"`, затем `npm run data`.
- Названия книг-источников показываются только по-английски.
- На широком экране (от 1100 px) в шапке есть переключатель вида: «Список» (список слева, карточка справа) или
  «Плитки» (плитки, сгруппированные по уровням, на 2/3 экрана, карточка — на 1/3; в режиме сравнения карточка шире).
  Выбор запоминается в браузере.
- Тема оформления (кнопка в шапке): как в системе (по умолчанию), светлая или тёмная. Выбор хранится в браузере
  (`dnd.theme`) и применяется скриптом в `index.html` до отрисовки, без мигания.

## Списки заклинаний персонажей

- «Мои списки» в шапке: список = персонаж; классы с уровнями (несколько классов — мультикласс), подкласс,
  модификатор характеристики (для числа подготовленных заклинаний). Кнопка «Подобрать заклинания» у класса
  включает в левой колонке подбор: показаны заклинания списка класса до доступного уровня, с кнопками «+».
  В карточке заклинания есть кнопка «В список».
- Ячейки и лимиты считаются по таблицам классов (`scripts/lib/casters.mjs`): официальные классы — из 5etools
  (PHB, артифисер — TCE; Мистический рыцарь и Мистический ловкач — PHB), мультикласс — по таблице PHB,
  Магия договора колдуна — отдельно. Классы Laserllama — из его документов классов
  (`data/laserllama/class-tables/*.json`); без документа — по таблице официального класса, у его собственных
  классов (Magus, Psion, Shaman, Vessel) таблиц нет. Добавить таблицу из документа класса:
  `python -P -E scripts/extract_class_table.py "<PDF>" Bard "Laserllama: Alternate Bard" cantrips,known,slots`
  (столбцы таблицы класса после «Features» слева направо: `cantrips`, `known`, `slots` — девять столбцов ячеек,
  `-` — пропустить), затем `npm run data`.
- Хранение: только в браузере, две копии — localStorage и IndexedDB (`dnd-user`), браузер просят сделать
  хранилище постоянным. Списки не пропадают при выходе, смене пароля и обновлении данных; удаляются только при
  полной очистке данных сайта. Есть сохранение копии в JSON-файл и загрузка из него. Safari (iPhone/Mac) может сам
  стереть данные сайта, если его не открывать 7 дней, — там стоит держать копию в файле.
- PDF (кнопка «PDF» в списке): RU или EN, «С описаниями» или «Таблица». Делается в браузере библиотекой pdfmake
  (грузится только при выгрузке); без картинок, шрифт Roboto встраивается только нужными символами —
  файлы получаются десятки килобайт.

## Листы персонажей (из Foundry VTT)

- Отдельные страницы на всю ширину экрана (без списка заклинаний и фильтров); настройки печати — в колонке справа.
- «Персонажи» в шапке: загрузка персонажа, экспортированного из Foundry VTT (система dnd5e 2.x–5.x; в Foundry:
  «Актёры» → правый клик → Export Data). Файл проверяется (`src/foundry.ts`) и хранится в сокращённом виде
  (без картинок, токена, служебных полей) так же, как списки: localStorage + IndexedDB `dnd-user`, копия в файл.
- Значения листа считаются из данных dnd5e (`src/sheet.ts`): модификаторы, спасброски, навыки (половина/полный/
  двойной бонус), пассивные значения, КД по формуле (доспех + ЛОВ с ограничением, щит, доспехи мага, защита без
  доспехов…), хиты по продвижению класса, кости хитов, атаки оружием (владение, фехтовальное, метательное,
  универсальное), атакующие заговоры с ростом урона, умения со спасброском (оружие дыхания), ограниченные умения
  (формулы `@prof`, `@scale…`, `@abilities…` — свой разборщик, без eval), ячейки (таблицы классов сайта; для
  неизвестных классов — по типу прогрессии), Сл и бонус атаки заклинаний, активные эффекты предметов.
- Заклинания сопоставляются с сайтом по английскому названию (Babele/Plutonium хранят оригинал); «(Alternate)» и
  источник LL — версия Laserllama. В лист идут названия и тексты сайта (RU/EN), остальные — из файла.
- Логика вместо слепого копирования: если импортёр пометил все заклинания подготовленного заклинателя «всегда
  подготовленными», так остаются только заклинания подкласса (по ссылкам `@spell[…]` в умении «… Spells» и спискам
  подклассов сайта). На странице персонажа можно поправить владение навыком и его характеристику, «всегда
  подготовлено», какие ограниченные умения печатать, а также заполнить игрока, мировоззрение, черты, историю.
- PDF (`src/sheetpdf.ts`, A4): основной лист на одной странице, умения и черты, заклинания по уровням с клетками
  подготовки и кружками ячеек, снаряжение с монетами и пустыми строками до конца страницы, личность и история,
  описания заклинаний. Настройки: описания умений и заклинаний, язык заклинаний, сколько пустых страниц под
  заклинания/снаряжение/заметки, пустые строки под каждым уровнем заклинаний, вписывать ли текущие хиты, крупный шрифт.

## Команды

```sh
npm install
npm run fetch          # скачать исходные данные (5etools, ttg.club), кэшируется в data/vendor
npm run data           # собрать данные и зашифровать их в src/data/spells.bin
npm run dev            # локально: http://localhost:5173
npm run set-password   # новый пароль (или: npm run set-password -- "свой пароль"), затем npm run data и push
npm run smoke -- <url> <пароль>   # проверка сайта в браузере
npm run test:lists -- <url> [пароль]   # проверка списков и PDF (без пароля — ключ из .env.local)
npm run test:chars -- <url> <персонаж.json> [пароль|-] [папка]   # проверка листов персонажей и PDF
```

Секреты (соль и ключ шифрования, хеши) хранятся только в `.env.local`, которого нет в репозитории.
После смены пароля все браузеры попросят ввести новый.
